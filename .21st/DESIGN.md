# Reading Habit website design

A quiet, responsive app introduction with a separate long-form user guide. Use the existing journal icon, neutral surfaces, charcoal text, restrained blue links and actions, and system typography. All content and navigation work without JavaScript.

The homepage leads with the app and a real sample Journal screen. Subsequent sections explain capture, reading, history, and goals. The guide uses a sticky desktop table of contents and a collapsible native disclosure on mobile, with permanent chapter anchors.

Keep screenshots legible and unaltered. Use sample data and current UI. Public release remains pending until a verified download exists.
